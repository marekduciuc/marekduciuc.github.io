Privacy policy

Last updated: 01.11.2026

Who uses this app

claudecode is a personal OAuth client. Its only intended user is its developer, Marek Duciuc, accessing his own Google account.

What data it accesses

With the user's consent, the app accesses Google Drive, Docs, Sheets, Slides, Gmail, Calendar and Tasks data through Google APIs, only when the user runs a command on his own computer.

How data is used and stored

  • Data is processed on the user's own computer to carry out the command he ran.
  • OAuth tokens are stored locally in the operating system's keyring.
  • The app has no server. No data is collected by, sent to or stored by the developer or any third party.
  • Data is not sold, shared, used for advertising, or used to train machine-learning models.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
